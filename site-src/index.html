How it works

Answer three questions. Get a book you can send.

1

You talk

What do you do? Who is it for? What do you want them to know? Plain answers, spoken or typed.

2

You turn the page

One link that opens like a book on any phone. Large type, a contents list that goes everywhere, a full-screen button.

The standard

Typeset like a printed book.

  • Two open-licence book fonts.Bodoni Moda for headings, Newsreader for text. Both open licence, embedded in the book.
  • Big enough for a phone.Text starts large and has A- and A+. No horizontal scroll at 390 pixels wide.
  • Full-screen button.Uses the browser's full-screen mode where it exists, and a hidden-toolbar mode where it does not.
  • Contents that reach every part.Chapters in a guide, every step in an adventure.
  • A page turn you can switch off.Respects reduced-motion. Sound is off until the reader asks for it.
  • Every path checked. No dead ends.The checker plays every path and lists the endings it reached.
  • Your words stay yours.The editor pass reports friction by page. It never rewrites your text.
  • One file, any host.A book is a single HTML file. It also runs from a USB stick.

Where it runs

It lives inside the agent you already use.

Status: the plugin passes Claude's strict validation and installs in Codex from the repo's marketplace manifest. The GitHub repo is public and installs out of the box; marketplace submissions are not complete.

Claude Code

Add the plugin, then type /make-book. The agent interviews you, writes, builds, checks and gives you the link.

/plugin marketplace add executiveusa/bookee
/plugin install bookee@bookee
/make-book

Codex and others

Anything that reads an AGENTS.md can run it. The same steps are plain commands.

git clone executiveusa/bookee
cd bookee && npm install
node bin/bookmaker.mjs plan --kind guide
node bin/bookmaker.mjs check books/mine
node bin/bookmaker.mjs build books/mine

Questions

Who writes the book?

Your agent drafts it from your answers. You read every page and change what you want. The tool lists problems page by page and leaves your sentences alone.

What does the reader need?

A link and a phone. No app, no account.

Can I put it on my own server?

Yes. The folder is static files. Copy it anywhere that serves web pages.

What about the pictures and music?

Each picture or song is a named slot. Drop the file in and rebuild. Until then the book shows a clearly labelled placeholder.
